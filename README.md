# CreatorAI Studio ✦

**O estúdio definitivo para criadores. Imagens e vídeos profissionais gerados por IA em segundos, sem limites e totalmente gratuito.**

## 🚀 Versão Ultra Premium 3D

Esta é a versão completamente reconstruída do CreatorAI Studio, com foco em **qualidade profissional**, **funcionalidade garantida** e **experiência de usuário de elite**.

### ✨ Principais Características

A plataforma oferece uma interface ultra-moderna com design 3D interativo, animações fluidas e um sistema robusto de geração de conteúdo. O background animado em Three.js cria uma atmosfera imersiva enquanto você trabalha. A geração de imagens utiliza a API do Hugging Face com fallback automático para geração local via Canvas, garantindo que você sempre consiga criar, sem exceções. Os vídeos são processados através de um motor cinematográfico avançado que aplica efeitos de zoom suave (Ken Burns), vinhetas profissionais e barras letterbox, transformando qualquer imagem em um vídeo de qualidade cinema. O histórico local permite recuperar suas últimas 12 criações instantaneamente, tudo armazenado no navegador para máxima privacidade.

### 🎯 Funcionalidades

- **Geração de Imagens**: Crie imagens em alta resolução com diversos estilos (Cinematográfico, Fotorrealista, Arte Digital, Anime, Cyberpunk, 3D Render)
- **Vídeos Cinematográficos**: Transforme imagens em vídeos profissionais com efeitos de câmera avançados
- **Múltiplas Proporções**: Suporte para 1:1, 16:9, 9:16 e 4:5, otimizado para todas as plataformas
- **Me Surpreenda**: Gerador de prompts profissionais integrado
- **Histórico Local**: Acesse suas últimas criações instantaneamente
- **Download Instantâneo**: Baixe em PNG (imagens) ou WebM (vídeos)
- **Interface Ultra Premium**: Design 3D com animações fluidas e glassmorphism

### 🛠️ Stack Tecnológico

- **Frontend**: HTML5, CSS3 (Grid/Flexbox), JavaScript ES6+
- **3D**: Three.js para animações de background
- **IA de Imagem**: Hugging Face Inference API + Fallback Canvas
- **IA de Vídeo**: Motor Cinematográfico Canvas com MediaRecorder
- **Armazenamento**: LocalStorage para histórico local

### 💡 Como Usar

1. **Digite um Prompt**: Descreva sua visão em detalhes
2. **Configure**: Escolha proporção e estilo
3. **Gere**: Clique em "Gerar Agora"
4. **Baixe**: Salve sua criação em PNG ou WebM

### 🎨 Design

O design segue princípios de **Glassmorphism** com uma paleta de cores sofisticada (Indigo, Púrpura, Ciano). As animações são fluidas e responsivas, com transições suaves entre estados. O background 3D com partículas flutuantes cria uma sensação de profundidade e movimento, enquanto os cards com efeito hover proporcionam feedback visual imediato.

### 🔐 Privacidade

Todas as operações ocorrem no navegador do usuário. Nenhum dado é enviado para servidores externos (exceto as requisições necessárias às APIs de IA). O histórico é armazenado apenas localmente no `localStorage`.
