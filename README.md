# CreatorAI Studio ✦

O **CreatorAI Studio** é uma plataforma ultra-profissional e minimalista para geração ilimitada de imagens e vídeos por Inteligência Artificial, rodando inteiramente no navegador.

## 🚀 O que há de novo?

Esta versão foi completamente reconstruída para eliminar limitações e custos:

- **Geração Ilimitada & Gratuita**: Substituímos o Puter.js pelo motor **Pollinations.ai**, permitindo criações infinitas sem necessidade de chaves de API ou assinaturas.
- **Cinematic Video Engine**: Um novo motor de renderização que transforma imagens estáticas em vídeos cinematográficos de alta qualidade com efeitos de *Ken Burns*, vinhetas e movimentos de câmera suaves.
- **Interface Ultra Pro**: Design moderno com Glassmorphism, ícones Lucide e uma experiência de usuário otimizada para desktop e mobile.
- **Privacidade Total**: Suas criações são processadas no navegador e o histórico é salvo apenas localmente no seu dispositivo (`localStorage`).

## ✨ Funcionalidades

- 🖼️ **Imagens de Alta Resolução**: Escolha entre diversos estilos (Cinematográfico, Anime, Cyberpunk, etc).
- 🎬 **Vídeos Cinematográficos**: Gere vídeos prontos para Reels, TikTok ou YouTube.
- 🎲 **Me Surpreenda**: Gerador de prompts profissionais integrado.
- ⬇️ **Download Instantâneo**: Baixe suas artes em PNG e vídeos em WebM/MP4.
- 📜 **Histórico Local**: Acesse suas últimas 12 criações instantaneamente.

## 🛠️ Tecnologias

- **Frontend**: HTML5, CSS3 (Modern Flexbox/Grid), JavaScript (Vanilla ES6+).
- **IA de Imagem**: Pollinations.ai API.
- **IA de Vídeo**: Cinematic Canvas Animation Engine.
- **Ícones**: Lucide Icons.

## 📦 Como usar

Basta abrir o `index.html` em qualquer navegador moderno ou publicar no **GitHub Pages** para ter seu próprio estúdio de IA online.
